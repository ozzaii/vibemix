# Plan 104-01 — Backend: what-remains payload + creditability fact + Mastered vocal

**Phase:** 104 (Skill-Tree Surface + Earned Celebration)
**Wave:** 1 of 2 (backend — pure-logic + Python tests; no schema/UI yet)
**Requirements:** SURF-01 (what-remains, Python single-source) · SURF-03 (Mastered vocal)
**Mode:** TDD (test RED → impl GREEN), surgical `--files` commits, learn-island only.

## Goal

Land the two backend gaps so the frontend wave has a validated payload field and a
fire-once Mastered-vocal hook to render/wire: (a) a deterministic, single-source-in-
Python `what_remains` string folded into `skill_wall_payload`; (b) a pure, fire-once,
slop-gated Mastered unlock vocal selection + its live `speak` hook at the credit site.

## Tasks

### T1 — Creditability becomes a readable manifest fact (SURF-01/03 honesty floor)
- `learn/skill_tree.py`: add `live_creditable: bool = True` to `SkillSpec`; set
  `beatmatching` → `live_creditable=False` in `SKILL_MANIFEST` (the only v11.0
  honest-uncreditable skill).
- **Drift pin** (new test `tests/learn/test_creditability_drift.py`):
  `{sid for sid, sp in SKILL_MANIFEST.items() if not sp.live_creditable}` ==
  `set(skill_recognizer._HONEST_UNCREDITABLE_V11)`. Keeps the manifest + recognizer
  single-truth — fails loud if either side drifts.

### T2 — `what_remains` in the payload (SURF-01) — TDD
- `learn/skill_tree.py`: a pure helper `_what_remains(sp: SkillProgress, spec: SkillSpec) -> str`
  (deterministic, no clock, never raises) with the labels from CONTEXT decision #2.
  Fold it into each `skill_wall_payload` row dict as `"what_remains"`.
  - Keep it OUT of `SkillProgress.as_payload` (that struct has no spec/threshold) —
    compute in `skill_wall_payload` where the tree + specs are in scope.
- **Test** `tests/learn/test_skill_wall_what_remains.py` (RED first): locked-no-lessons,
  locked-lessons-done-no-recital, competent-creditable (N−count phrasing + singular/plural),
  competent-uncreditable (beatmatching → honest, NO "soon"/"coming"), mastered ("").
  Assert no anti-slop token leaks into the labels (cheap inline blocklist subset check).

### T3 — Mastered unlock vocal: pure fire-once selection (SURF-03) — TDD
- `learn/transcripts/earned/mastered_vocals.json` (NEW): hand-authored copy —
  `{"_default": "<line>", "<skill_id>": "<line>", ...}`. Slop-gated automatically by
  `check_no_tutor_slop` (scans `learn/transcripts/**.json`). Tone: real friend marking a
  genuinely-earned moment, NOT gamification ("Achievement unlocked!"). Final tone parks
  as `§EARNED-MASTERED-VOCAL-EAR`.
- `learn/mastered_vocal.py` (NEW): import-light (stdlib + fixture read only).
  - `mastered_unlock_line(skill_id, *, was_mastered: bool, now_mastered: bool) -> str | None`
    returns the line IFF `(not was_mastered and now_mastered)`; else `None`. Fire-once by
    construction (only the transition is non-None; a re-call with `(True, True)` → None).
  - Copy loaded once from the fixture; unknown skill → `_default`; missing fixture →
    honest hard-coded fallback (never raises).
- **Test** `tests/learn/test_mastered_vocal_fires_once.py` (RED first): flip→line;
  already-mastered (True,True)→None; no-flip competent (False,False)→None; second call after
  flip→None (fires exactly once); returned line passes the tutor-slop blocklist; the
  fixture file exists and is valid JSON with a `_default`.

### T4 — Wire the vocal into the live credit site (SURF-03 "routed through co-host") — TDD
- `runtime/coach.py`: extend `_credit_live_skill_demo(...)` with an injected
  `speak: Callable[[str], None] | None = None` kwarg. Before `recognize`, snapshot each
  candidate skill's `mastered` bool; after a real credit, for each credited skill that
  flipped not-mastered→mastered, call `mastered_unlock_line(...)` and `speak(line)` —
  exactly once per flip, guarded never-raises (a vocal failure must never wedge the loop).
- In `coach_loop`, build `speak` from the existing `session` (fixed-text co-host path,
  `hasattr(session, "say")` guard — NO `generate_reply`/LLM, NO new provider) and pass it
  to `_credit_live_skill_demo`. Default `speak=None` keeps every existing caller + test green.
- **Test** (extend `test_mastered_vocal_fires_once.py` or a coach seam test): inject a
  recording `speak` + a progress where one cited demo flips a Competent skill → `speak`
  called once with the right line; a second cited demo (already mastered) → `speak` NOT
  called again; an un-cited event → no credit, no `speak`.

EventDetector (src/vibemix/state/event_detector.py):
  EventDetector(audio_buf=None, *, evidence_registry=None)
  .detect(state: MusicState, *, kaan_just_spoke: bool, manual: bool) -> Event | None
  Auto-events gated by _music_truly_playing: requires state.audible sustained for
  MUSIC_PRESENCE_MIN_SECONDS (4.0s) AND BPM in [BPM_VALID_MIN=100, BPM_VALID_MAX=180].
  PHASE fires when state.phase != last_phase and phase not in ("silent",) and cooldown ok.
  LAYER_ARRIVAL fires on a mid_jump>0.15 or high_jump>0.10 band-signature delta + rms>LOW_RMS + not vocal_active.
  Per-type cooldowns via _cooldown_ok using MIN_EVENT_GAP_PER_TYPE (PHASE=10.0, LAYER_ARRIVAL=10.0) + EVENT_GLOBAL_MIN_GAP=10.0.

MusicState (src/vibemix/state/music_state.py): plain object; tests set fields directly.
  Relevant fields: audible (bool), bpm (float), phase (str), bands (dict sub/low/mid/high),
  rms (float), recent_moves (list[(age,label)]), audible_track, audible_track_confidence.

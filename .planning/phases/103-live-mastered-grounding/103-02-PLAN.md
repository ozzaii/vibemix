It maps a detected live event to the skill(s) it demonstrates via a reverse map keyed on REAL `state/event_detector.py` event-type string literals, gates each candidate skill on (a) being Competent (MAST-01, delegated to the Plan-01 mutator) and (b) an INJECTED citation predicate resolving true (MAST-03 — un-cited / fabricated → ZERO credit), dedups by event identity, then applies credit through `skill_tree.record_live_demo` (Plan 01).

From src/vibemix/state/event_detector.py + state/event.py (READ-ONLY — confirm strings, do NOT edit; concurrent session owns state/):
- `Event.type: str` — a PLAIN STRING LITERAL, no enum. `Event` fields: `type`, `state`, `extra` (dict), `priority`. No stable id field.
- The exact fired event-type literals (verified this session): `MIX_MOVE`, `LAYER_ARRIVAL`, `PHASE`, `PHRASE_BOUNDARY`, `MANUAL`, `KEY_CLASH`, `TRANSITION_OPPORTUNITY`, `TRACK_CHANGE`, `HEARTBEAT`, `DROP`, etc.
- `MIX_MOVE` carries `event.extra["moves"]` — a list of move-label strings. EQ-band twists/kills contain substrings `_low:`/`_mid:`/`_hi:`/`killed`; deck/transport contain `_play→`/`xfader`. (event_detector.py:325-340)
- The EventDetector writes the citation at fire time as `registry.write("ev", ev_type, t_session)` (event_detector.py:509) — so the citation key for an `ev` credit is `(source="ev", key=event.type, t_target=<event's t_session>)`.

From src/vibemix/state/evidence_registry.py (READ-ONLY — the predicate WRAPS this; do NOT import it for runtime use):
- `has(source: str, key: str, t_target: float, tol: float = 1.0) -> bool` (evidence_registry.py:386) — True iff an observation at (source, key) lies within ±tol of t_target; missing source/key → False (no raise). The injected `citation_check` predicate has this shape: `Callable[[str, str, float], bool]`. In live wiring (DEFERRED — see KAAN-ACTION below) it is `lambda s, k, t: registry.has(s, k, t, tol=1.0)`; in tests it is `lambda s, k, t: True` (cited) / `lambda s, k, t: False` (uncited).

## Scope & Reuse Anchors

The pill is a **third Tauri overlay webview** (after `mascot_window`, `debrief_window`).
It does NOT introduce a new design language — it inherits the CDJ-Whisper v5
system already shipped in `tauri/ui/src/tokens.css` (the design source of truth)
and reuses these existing components and wire shapes verbatim:

| Asset (existing) | Path | Pill reuse |
|------------------|------|-----------|
| Design tokens | `tauri/ui/src/tokens.css` | ALL color / type / spacing / glow / motion — components read `var(--token)`, never hex |
| Transparent-overlay override | `tauri/ui/mascot.html` + `tauri/ui/overlay.html` | `html,body { background: transparent !important; background-image: none !important }` + `body::before { display:none }` — mandatory invariant for any always-on-top webview |
| Citation strip | `tauri/ui/src/session/components/citation-strip.ts` (`CitationChip {event_id, verb, timestamp_s}` + `--c-citation-chip-*` tokens) | Render the same chip strip in the expand state — DO NOT re-implement |
| TTS waveform source | `meters.voice.rms` / `voice.peak` from `ipc.session.snapshot` (the `Levels.update_voice` AI-speech RMS already on the bus) | Drives the `speaking` waveform — real signal, not a fake animation |
| Reaction push | `ipc.session.cohost-reaction` (`{text, event_id, citation_strip[]}`) | Triggers `expand-on-event`; supplies reaction text + chips |
| Status state | `cohost_status ∈ {IDLE, LISTENING, TALKING}` from snapshot | Maps to pill `idle` / `listening` / `speaking` states |
| Deck context | `track {title, deck}` + `bpm` + `key` (snapshot) + Phase 59 `deck_state` per-deck title/key/BPM | Deck-context chips in expand; honest `unknown` when unresolved |
| Window mechanics | `tauri/src-tauri/src/mascot_window.rs` (geometry-persist, 200ms debounce, label↔capability test) | Clone → `pill_window.rs`; do NOT copy `set_ignore_cursor_events(true)` |

**Out of scope (no scope creep):** notch-locked pill, new ws port, Python delivery
changes, retiring the mascot, new AI providers, pill→Python command channel.

## Spacing Scale

The pill uses the existing 8-point-derived `--sp-*` scale from `tokens.css`.
All values are multiples of 4.

| Token | Value | Pill usage |
|-------|-------|-----------|
| `--sp-1` | 4px | Icon-to-text gaps, chip inner gap, waveform bar spacing |
| `--sp-2` | 8px | Compact pill internal padding (collapsed), inter-chip gap |
| `--sp-3` | 12px | Pill horizontal padding, drag-handle inset |
| `--sp-4` | 16px | Expand-panel body padding, reaction-text block spacing |
| `--sp-5` | 24px | Expand-panel section separation (reaction ↔ chips ↔ deck chips) |

Larger tokens (`--sp-6`..`--sp-8` = 40/64/96) are NOT used — the pill is a compact
surface; layout-scale spacing belongs to the full session view, not the pill.

**Exceptions:**
- **Drag-handle hit-target: 28px tall minimum** (the top strip of the pill is the
  drag region). Rationale: a sub-24px drag strip is unreliable to grab on an
  unfocused window; 28px (= `--sp-2` + 20px content row) keeps it grabbable without
  breaking the 8-point grid for visible spacing. This is a hit-area, not a visible
  spacing token.
- **Collapsed pill height: 44px** (`--sp-5` + 20px content). Rationale: matches a
  comfortable always-on-top read at 2 AM and stays a single multiple-of-4 step.

## Typography

3 sizes, 2 weights. All from the existing Saira + JetBrains Mono stack.

| Role | Size | Weight | Line Height | Font | Pill usage |
|------|------|--------|-------------|------|-----------|
| State label | 9px | 500 (medium) | 1.0 | Saira (wdth 85, wght 500), 0.22em tracking, UPPERCASE | `IDLE` / `LISTENING` / `SPEAKING` caption in the collapsed strip — the silkscreen-label convention |
| Reaction body | 13px | 400 (regular) | 1.5 | Saira (wdth 100, wght 400) | The AI reaction text in the expand state (max 3 lines, ellipsis after) |
| Chip / numeric | 10px | 500 (medium) | 1.0 | JetBrains Mono, tabular-nums, lowercase | Citation chips (`[kick swap @ 0:45]`) + deck-context chips (`a · 8a · 128`) |

Exactly **2 weights** (400 regular + 500 medium). No 600/700 on the pill — bold
display weight belongs to the full session hero, not the compact floating surface.
Line heights: body 1.5 (legibility at small size), labels/chips 1.0 (single-line).

## Color

The pill is overwhelmingly dark glass with a single amber accent — the 20/80 rule
holds (frontend-enforcement hard rule 2). Tokens are existing `tokens.css` vars.

| Role | Token | Value | Pill usage |
|------|-------|-------|-----------|
| Dominant (≈80%) | `--glass-3` over transparent | `rgba(2,3,6,0.88)` | The pill surface itself — near-opaque dark glass via the explicit `--glass-*` rgba fallback (NOT OS vibrancy). The 80% dominant tone. |
| Surface ink | `--silk` / `--silk-65` / `--silk-40` | `#d6cfc7` + alphas | Reaction text (`--silk`), state labels (`--silk-65`), inactive meta (`--silk-40`) |
| Secondary structure | `--glass-edge` + `--glass-top` | `rgba(255,255,255,0.065)` + `0.055` | 1px hairline border + top inner-light seam (the "sealed glass" read) |
| Accent (≈20%) | `--amber` (+ `--amber-22/40/65`) | `#ff8a3d` | RESERVED list below |
| Citation chips | `--c-citation-chip-*` | amber-pale fg / amber-22 border / amber-04 bg | The chip strip's only accent — inherited from `citation-strip.ts` |
| Destructive | `--led-fault` (`--rec`) | `#d4413a` | NOT used on the pill — there are no destructive actions in this phase |

**Accent (`--amber`) reserved EXCLUSIVELY for:**
1. The **live/state dot** in the collapsed strip (pulses only in `listening`/`speaking`, per the existing `liveBlink` cadence).
2. The **TTS waveform fill** during `speaking` (the `--amber-deep → --amber → --amber-pale` gradient, matching the session meter fill).
3. **Citation chips** in the expand state (via `--c-citation-chip-*`, resting glow = none, hover = `--glow-soft`).
4. The **deck-resolved key glyph** inside a deck-context chip (amber when a real key resolved; `--silk-40` when `unknown`).

Accent is NOT spread to: the pill border (hairline silk), drag handle, reaction
text, deck title/BPM, or any background. If amber appears anywhere outside this
4-item list, the 20/80 rule is broken.

**Glass transparency parity (PILL-04):** the visible surface MUST use the explicit
`--glass-3` rgba fallback (`rgba(2,3,6,0.88)`), NOT pure OS vibrancy. This guarantees
mac+win parity (no opaque-white box on Windows) and dodges the DMG transparency
regression (tauri#13415). The window is `transparent(true)` + `decorations(false)`;
the rgba fill is what the user actually sees. `backdrop-filter: var(--blur-glass)`
is a progressive enhancement layered ON TOP of the opaque-enough rgba — never the
sole opacity source.

## Pill States (PILL-03) — interaction contract

Four states, each mapped to existing wire data. Transitions are state-machine pure
(mirror the mascot's `state.ts` discipline).

| State | Trigger (wire) | Collapsed visual | Motion |
|-------|----------------|-------------------|--------|
| `idle` | `cohost_status === "IDLE"` (or no session) | State dot `--silk-40` (dim, no pulse); label `IDLE`; flat baseline (no waveform) | None — the pill is at rest, a faint sign-of-life only |
| `listening` | `cohost_status === "LISTENING"` | State dot `--amber`, slow `liveBlink` (1.4s); label `LISTENING`; a thin idle "breathing" line (NOT music-reactive — avoids implying the AI is talking) | `liveBlink` only |
| `speaking` | `cohost_status === "TALKING"` | State dot `--amber`, fast `liveBlink` (0.9s); label `SPEAKING`; **real TTS waveform** driven by `meters.voice.rms` (amber gradient fill, segmented like the session meter `.m-fill`) | Waveform updates at the 30Hz snapshot cadence; bars ballistically decay |
| `expand-on-event` | `ipc.session.cohost-reaction` received | Pill grows DOWN to the expand panel: reaction text (≤3 lines) + citation strip + deck-context chips. After ~6s of no new reaction, collapses back to the prior state. | Expand: 200ms `--motion-transition` ease-out (height + opacity); collapse: same, reversed. ONE orchestrated reveal, not scattered micro-effects (frontend-enforcement rule 6). |

**Waveform spec:** segmented vertical bars (12–16 bars), each height = recent
`voice.rms` window, fill = `linear-gradient(90deg, --amber-deep, --amber 65%, --amber-pale)`
with the existing `.m-fill::after` 4px dark-comb overlay for the hardware-LED read.
This is the SAME visual language as the session meter — reuse, do not invent. When
`voice.rms` is silent (between phrases) the bars settle to a flat low baseline, not zero.

**Deck-context chips (expand only):** one chip per resolved deck — `<deck> · <key> · <bpm>`
(e.g. `a · 8a · 128`). Key glyph amber when resolved, `--silk-40` when the source
returned `unknown` (Phase 59 honest-fallback — never a false-confident guess). If
NO deck resolves, render a single `decks · unknown` chip in `--silk-40`. The chip
key MUST come from registry-observed `key:` evidence (Phase 59 citable source), never
fabricated.

**Drag handle:** the top 28px strip is the drag region. Primary mechanism =
explicit JS `getCurrentWindow().startDragging()` on `mousedown` over the handle
(`data-tauri-drag-region` kept as progressive enhancement — unreliable alone on
non-activating windows per tauri#11605/#10767). Visual affordance: a faint 2px ×
20px `--silk-22` grab-bar centered in the top strip (the only non-amber affordance).
Cursor: `grab` → `grabbing` on mousedown.

## Copywriting Contract

The pill carries minimal chrome copy. All strings must pass the anti-slop blocklist
(15-token + `deeply\s+\w+` regex). State labels are the silkscreen vocabulary, lowercase
deck chips, no marketing voice.

| Element | Copy |
|---------|------|
| Primary CTA | None — the pill has no button-CTA (it is a consume-only surface for v1, per CONTEXT "Deferred: pill-driven controls"). The only interaction is drag + chip-click. |
| State label · idle | `IDLE` |
| State label · listening | `LISTENING` |
| State label · speaking | `SPEAKING` |
| Empty state heading | `IDLE` (the idle state IS the empty state — no session / no reaction yet) |
| Empty state body | No body text. A pill with nothing to say shows the dim dot + `IDLE` label only — silence is the honest empty state, not a "waiting for your set…" filler line (anti-slop: no scripted chatter). |
| Deck chip · unresolved | `decks · unknown` (lowercase, `--silk-40`) — honest, never a fake key |
| Reaction text | Verbatim from `ipc.session.cohost-reaction.text` — the pill renders the grounded AI line as-is; it does NOT add framing, prefixes, or "AI:" labels. |
| Citation chip text | `<verb> @ <mm:ss>` — verbatim from `citation_strip[].verb` + `timestamp_s` (existing `citation-strip.ts` format). |
| Error state | If the ws:8765 bus is unreachable: the pill stays in `idle` with the dim dot (no error banner). Rationale: an always-on-top error toast over the DJ's deck is more disruptive than silence; bus-health surfaces in the main session window's status strip, not the pill. A connection-lost condition is logged, not painted. |
| Destructive confirmation | None — there are no destructive actions on the pill in this phase. |

**Copy register check:** no exclamation hype, no "let's", no "🎉", no generic
assistant voice. The pill speaks in CDJ-panel silkscreen (uppercase state labels,
lowercase mono data) — the reaction text's voice is owned upstream by the Phase 61
coach persona, not by pill chrome.

## Window / Tauri Contract (PILL-01, PILL-02, PILL-04)

These are interaction-contract items the executor must honour (sourced from
CONTEXT Areas 1–2; the felt-confirmation of drag/focus/transparency is the only
KAAN-ACTION carve-out — surface, do not pause).

- **Transparency:** `transparent(true)` + `decorations(false)`; visible surface = explicit `--glass-3` rgba (NOT pure vibrancy). Verify on the built `.dmg`.
- **Always-on-top + non-focus-steal:** macOS = non-activating `NSPanel` (`NSWindowStyleMaskNonactivatingPanel`) + `.focused(false)` at build. Clicking the pill must NOT pull keyboard focus off the DJ app.
- **NOT click-through:** the pill is interactive — do NOT call `set_ignore_cursor_events(true)` (the mascot's click-through line).
- **Drag:** explicit `startDragging()` on the handle; `data-tauri-drag-region` as progressive enhancement; resolve the winning combination on the BUILT app FIRST (the spike).
- **Geometry:** persist x/y/w/h with the mascot's 200ms-debounce pattern; clamp-to-visible on display change (multi-monitor).
- **Capability:** add a `"pill"` window-label entry to `capabilities/default.json` covering `window:allow-start-dragging` + the pill's IPC (mirrors the mascot allowlist; closes the v0.1.0-rc1 drag-capability debt).
- **`primary_surface` tri-state:** `config.rs` key `primary_surface ∈ {pill (default) | mascot | none}`; legacy/missing decodes to `pill`; surface choice applies at session start (no hot-swap v1). Mascot stays opt-in/secondary — `mascot-audit` CI fence MUST stay green.
- **One socket:** consume existing `ws://127.0.0.1:8765` frames only — no new port, no Python delivery change.

<objective>
Surface the auto-detected genre on the bus so the UI (and the Phase 56 mascot) can show "what's playing" honestly. Add `detected_genre` + `genre_confidence` to the 30Hz mascot frame in `ws_broadcast`, sourced from the MusicState fields written by Plan 52-03 — exactly the way `phase`/`bpm`/`mood`/`active_genre` are already carried. The hard anti-slop rule (GENRE-02): the wire shows `unknown` whenever the detector is unsure, never a hallucinated label — mirroring the `active_genre` "unknown" honesty already on the wire.

Purpose: GENRE-02 closes the loop — the grounded detection from Plan 03 is useless if the UI can't read it, and a hallucinated genre label on the UI is exactly the AI-slop failure class the product forbids. The fields are strictly additive so they cannot regress Phase 51's empty-frame cleanliness or the 30Hz cadence.

Output: two additive keys in the mascot frame + a payload-capture test that pins the fields, the values, the unknown-honesty case, and the no-empty-frame-guard-trip property.
</objective>

EvidenceRegistry (src/vibemix/state/evidence_registry.py):
  reg.write(source, key, t_session) — append-only.
  reg.register_library(lib, t_session=0.0) -> int — registers track:<id> for every id in lib.tracks (a dict). Duck-typed: any object with a .tracks mapping works (no full RekordboxLibrary needed). Returns count.
  reg.snapshot() -> {src:{key:(t,...)}}.
  reg.has(source, key, t_target, tol=1.0) -> bool — True iff some obs at (source,key) within ±tol; missing source/key → False (no KeyError).
  parse_citations(text) -> list[(source, body)] — walks EVIDENCE_CITATION_RE; body retains key@t for ev/aud/midi; free-form for track/screen/mix/tend.

CitationLinter (src/vibemix/coach/citation_linter.py):
  check(text, registry_snapshot, *, mode="live") -> LintResult(valid, citations_found, missing, reason).
  Time-keyed sources (ev/aud/midi): body must contain "@"; trailing float is t; lookup snapshot[source][key] within ±tol.
  Existence-only sources (track/screen/mix/tend): presence check body in snapshot[source].
  reason: "no_citations" / "malformed_atom" / "invalid_atoms" / "valid".

Constants (src/vibemix/coach/constants.py): LIVE_TOLERANCE_S = 1.0; DEBRIEF_TOLERANCE_S = 2.0.

Fixture (tests/fixtures/hype_trace_genre1.jsonl): JSONL; event lines {"t":<sec>,"kind":"event","type":"PHASE"|"MIX_MOVE"|"HEARTBEAT"|"LAYER_ARRIVAL"|"TRACK_CHANGE", "track":..., "track_conf":...}. The "t" is session-relative seconds. Use it to build the registry: for each event line write reg.write("ev", line["type"], line["t"]).

Debrief resolution reference (tests/debrief/test_drill_citations_resolve.py): _citation_resolves("[ev:MIX_MOVE@01:23]", SNAPSHOT) — the debrief path resolves at ±2.0s (mode="debrief"). The SNAPSHOT shape there mirrors the live snapshot. This plan's consistency test uses CitationLinter.check directly with mode="live"/"debrief" rather than the debrief helper, to assert one-grammar-two-bands at the linter boundary.

<orphan_definition>
An ORPHAN is a citation atom emitted by the model that does NOT resolve to a real EvidenceRegistry entry within the mode tolerance. "Zero orphans" means: for the set of citations a grounded reply emits against a registry built from real session data, CitationLinter.check(...).valid is True AND every parsed atom resolves via has(...). A hallucinated id (not in the registry) MUST be an orphan (valid False, in .missing). The test builds BOTH the all-resolve case (zero orphans) AND the injected-hallucination case (one orphan, stripped).
</orphan_definition>

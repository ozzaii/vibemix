<design_note>
slop_ratio = cumulative stripped/total (lifetime-of-session). This is the "what fraction of model turns got stripped" metric LIVE-04 wants — distinct from the 15s rolling rate (stripped_rate_15s) which is the bypass-guard signal. Both come off the SAME record() decisions: total bumps on every record(), stripped bumps on record(True). slop_ratio() = stripped/total, 0.0 when total==0. The cumulative counters are NOT windowed (lifetime per session) and NOT evicted — they are a separate pair from the rolling deque. Keep them plain ints; no lock (single-threaded contract). The clear-on-session boundary is the tracker's lifecycle (a new tracker per session via __main__), so no explicit reset needed.
last_unverified: a single str|None holder is sufficient for SessionCitationPayload (the schema field is str|None). Set it on strip OR bypass when unverified_text is provided; leave it on a clean emit. "Most recent" semantics = overwrite on each unverified emission.
</design_note>

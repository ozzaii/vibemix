<objective>
Close the BRINGUP-04 ws_bus cleanliness defect observed live this session: a tap of `ws://127.0.0.1:8765` showed intermittent empty `{}` frames interleaved with real level frames. Fix it at the emit boundary (the broadcaster must never serialize an empty/meter-less payload onto the wire) AND at the root cause (grep down whichever path actually produces the empty frame), then pin both with an `integration`-marked regression test that also doubles as the BRINGUP-01 boot-smoke (ws_bus reaches `phase=silent` cleanly, no empty frames over a sample window).

Purpose: this is the foundation phase — nothing downstream can be trusted if the wire carries garbage. The empty frames make every UI panel + the mascot renderer momentarily read a stateless frame, which is exactly the "AI slop / breaks the flow" failure class the product forbids.

Output: a defensive guard in `ws_broadcast`, the source fix, and `tests/runtime/test_ws_bus_empty_frames.py`. The mascot frame shape + 30Hz cadence stay byte-identical (pinned by existing tests).
</objective>

`ws_broadcast` (src/vibemix/runtime/ws_bus.py:185) emits TWO frame kinds on the same socket:
1. Mascot frame @30Hz (lines 262-277): `json.dumps({**levels.snapshot(), "audible":..., "deck":..., "phase":..., "bpm":..., "mood":..., "bpm_confidence":..., "downbeat_phase":..., "beat_phase":..., "active_genre":..., "emotion":..., "reaction_intent":...})`. Always ≥12 keys when levels.snapshot() + state are well-formed.
2. ipc.session.snapshot @15Hz (every SNAPSHOT_EVERY_N=2 ticks, lines 291-311): built by `_build_session_snapshot`, schema-validated, then json.dumps. Always a typed `{"type":"ipc.session.snapshot","payload":{...}}` envelope — proven non-empty by tests/runtime/test_ws_bus_snapshot.py.

`Levels.snapshot()` — returns the meter dict spread into the mascot frame. The mascot frame can only degrade to `{}` if BOTH the spread is empty AND all static keys vanish — which the literal code cannot do. So the live `{}` MUST come from either a Levels.snapshot() returning {} merged with a code path that strips static keys, OR a SEPARATE writer on :8765, OR the tap mis-decoding control frames. RESEARCH §1 ranks these (H1/H2/H3).

<objective>
Land the cross-process propagation seam: a side-channel file (`VIBEMIX_STOP_REASON_FILE` env var → temp path) that the MCP subprocess's `LibraryToolset` writes on threshold-trip and the parent-process wrapper (`curate_with_codex` / `build_set_with_codex`) reads after Codex exits. Purpose: Bridge the in-process toolset signal (Plan 99-03) to the wrapper-level result API so CLI / Telegram / GUI callers see a uniform `stop_reason`. This is the load-bearing architectural seam — it bypasses the LLM entirely (Channel A in RESEARCH.md § Stop-Reason Propagation Channel).

Output: `_write_side_channel(payload)` method on `LibraryToolset`; `VIBEMIX_STOP_REASON_FILE` allocation + env-var injection + post-`_runner` read in BOTH `curate_with_codex` and `build_set_with_codex` (located at `codex_curate.py:382` and `codex_curate.py:672` per RESEARCH.md); four propagation tests in a new `tests/library/test_codex_curate_stop_reason.py` file; two side-channel tests in the existing starvation test file.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-99-06 | Tampering | Side-channel file path injection | mitigate | Wrapper allocates the path inside `tempfile.TemporaryDirectory(prefix="viber-codex-")` (mode 0o700 on macOS/Linux). The MCP subprocess inherits the env var via `subprocess.run(..., env=env)`. A malicious local process cannot inject the env var — the wrapper writes the env dict last. T-99-06 mitigation per RESEARCH.md Security Domain. |
| T-99-07 | Race condition (TOCTOU) | Side-channel file race | mitigate | The file is written by the toolset (in-process inside MCP subprocess), read by the wrapper AFTER `_runner` returns (after Codex process has exited). No concurrent writers. The wrapper's read is a single `json.loads` of a final state. |
| T-99-05 | Information disclosure | Hint contents in the file | accept | The hint string (Decision 5 seed) contains only literal strings + the user's `theme` query — no FS paths, no library cache paths. The file lives in `tempfile.TemporaryDirectory` (auto-cleaned, mode 0o700). On macOS that's `/var/folders/.../T/viber-codex-XXXX/` (user-owned). Not leaked across users. |
| T-99-08 | Validation bypass | Malformed file contents | mitigate | Wrapper-side `try/except (OSError, json.JSONDecodeError): pass` + `isinstance(payload, dict)` + `payload.get("reason") == "tool_starvation"` defense-in-depth check (RESEARCH.md Code Example). Malformed file → graceful fall-through to existing parse logic. `test_malformed_side_channel_falls_through` pins this. |

Actually since `band` controls a COLUMN name (not a value), pure `?` binding is impossible — so use the allowlist + dictionary-key lookup pattern (validates THEN interpolates), e.g.:

```python
_BAND_TO_COL = {"sub": "sub_share", "low": "low_share",
                "mid": "mid_share", "high": "high_share"}
def top_for_band(conn, band, k=3, max_kick_corr=0.8):
    if band not in _BAND_TO_COL:
        raise ValueError(f"unknown band {band!r}; must be one of sub/low/mid/high")
    col = _BAND_TO_COL[band]
    sql = (
        f"SELECT track_id, {col}, kick_corr FROM band_shares "
        "WHERE kick_corr < ? "
        f"ORDER BY {col} DESC, track_id ASC LIMIT ?"
    )
    rows = conn.execute(sql, (max_kick_corr, k)).fetchall()
    return [(r[0], float(r[1]), float(r[2])) for r in rows]
```

(Column name is interpolated from an internal allowlist, not user input — STRIDE T-93-02-01 mitigated.)

`messages.schema.json` top-level shape:
- `"oneOf": [ ... ]` array of `{"$ref": "#/definitions/<EnvelopeName>"}` entries.
- `"definitions": { "<EnvelopeName>": { ... } }` for each envelope.
- Every envelope: `{ type: object, additionalProperties: false, required: ["type","ts","payload"], properties: { type: {const: "ipc.foo.bar"}, ts: {format: "date-time"}, payload: {...} } }`.

`src/vibemix/ui_bus/messages.py` shared helpers:
- `_now_iso()` — ISO-8601 UTC timestamp string.
- `_serialize(obj)` — `dataclasses.asdict` + `json.dumps` with sorted keys.
- `_VALIDATOR` — module-level `jsonschema.Draft7Validator` already loaded against `messages.schema.json`.

`tauri/ui/vite.config.ts` `rollupOptions.input` shape:
```
input: {

}
```

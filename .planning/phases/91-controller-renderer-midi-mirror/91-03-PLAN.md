`ControllerState.deck_snapshot()` (existing, `src/vibemix/midi/state.py:144`):
- Returns a lock-guarded dict shaped `{"A": {field: int, ...}, "B": {field: int, ...}, "xfader": int, "connected": bool}`.
- Per-deck fields: `vol`, `eq_low`, `eq_mid`, `eq_hi`, `filter`, `tempo` (CC 0..127), plus booleans `play`, `cue`, `jog_touched` (0/1 in the wire shape).
- This is the ONLY read API `MidiMirror` should call. No second listener; no direct mido access.

`port_watcher_task` (existing, `src/vibemix/midi/watcher.py:39`):
- Polls `mido.get_input_names()` at 2 Hz.
- On change, fires an `on_change` callback with `("connected", port_name, profile)` or `("disconnected", port_name)`.
- The `handle_port_change_single_state` adapter in `platform/_midi_common.py` is where the callback currently lands; we extend it to also fire the `MidiMirror.controller_detected(...)` envelope emit.

`ws_broadcast` (existing, `src/vibemix/runtime/ws_bus.py:276+`):
- Async loop ticking at 30 Hz; the mascot frame and snapshot frame are emitted inside this loop.
- Already accepts kwargs (`levels`, `state`, `transcript_buf`, `controller_state`, `suggestion_holder`, `tracer`, `ipc_router`, `screen_available`); we add ONE new kwarg `midi_mirror=None`.
- The 30 Hz tick is `await asyncio.sleep(1.0 / 30)`; mascot/snapshot emit happens before the sleep; we add the `midi_mirror.snapshot()` pull immediately after the mascot emit, before the sleep.

`__main__.main()` (existing, `src/vibemix/__main__.py:843+`):
- Instantiates `midi_macos = MidiMacOS()` (or Windows equivalent on Windows) at ~line 844.
- Calls `asyncio.create_task(ws_broadcast(...))` later; we insert `midi_mirror = MidiMirror(controller_state=midi_macos.controller_state)` between these two events and thread it into the `ws_broadcast(...)` kwarg list.

<objective>
Land the mode picker on the main session window — a 4-mode (cohost / learn / build /
debrief) rocker, an `ipc.session.set_mode` envelope, and a `mode` enum on
`SessionState`. Implement the optimistic-repaint pattern (CLAUDE.md rule) so the
active segment flips LOCALLY in the click handler and the round-trip self-corrects.
Wire the first-launch tutor announce-by-name on `ipc.learn.controller_detected`
(the second permitted "Let's go." exception).

This plan is frontend-heavy. The Python side wires a thin handler that persists
the mode via `ConfigStore` (mirrors the `mood` / `click_through` pattern) and
emits the announce-by-name tutor line on first connection per app run.
</objective>

<what>Wire the sidecar handler for `ipc.session.set_mode` in `src/vibemix/runtime/`.</what>
<why>Receive the envelope, persist via `ConfigStore.extra` under key `session.mode`, ack with no echo. The mode is a UI state — the sidecar persists so the next launch boots into the last-picked mode.</why>

2. Add a sibling handler `_on_session_set_mode(msg)` that:

4. Add a settings.state mirror: when the sidecar emits `ipc.settings.state`, include `mode` from `config_store.get_extra("session.mode", "cohost")` so on cold-boot the shell reads the persisted last mode.
</how>

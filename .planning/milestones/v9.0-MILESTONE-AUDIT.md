## Executive Summary

v9.0 turned vibemix into the **AI beginner-DJ teaching module**: open the app, pick **Learn**, three progressive courses (Anatomy of a Deck · Transitions · Play Mode) walk a stranger through DJing with **THEIR specific MIDI controller mirrored on screen** as an interactive vector visualization, with the AI highlighting physical controls in real time, narrating in a hand-authored tutor voice, and proving each EQ band audibly by pulling a track from **THEIR library** where that band is most prominent — so as they turn the knob, they HEAR the band swell.

The build is **purely additive** on top of v8.x: ONE new Python dep (`python-statemachine`, MIT pure-Python ~30 KB), ZERO new JS deps, ZERO new ws ports (everything rides existing `127.0.0.1:8765`), ZERO new AI providers (Gemini Flash via `model_router.resolve("learn_tutor")` for tutor + scripted hand-authored copy for the 36 lessons, no Codex fallback). All 10 supported MIDI controllers (Pioneer DDJ-FLX4 / FLX6 / FLX10 / 400 / 1000 / SX3 · XDJ-RX3 · Numark Party Mix Live · Hercules Inpulse 300 / 300-MK2 / 500) have CDJ-Whisper-styled inline SVG schematics with full `<g data-control-id="…">` hit regions, painted in ≤16 ms per highlight via CSS-variable swap (no full SVG re-render), accessible with ARIA roles + dual-channel (color + shape) cues for color-blind users.

**The three milestone-blocking risks** were all mitigated up-front:

- **(P1) Tutor tone slop.** Mitigated by (a) hand-authored lesson scripts in `src/vibemix/learn/transcripts/course_{1,2,3}/*.json` — never LLM-generated on the fly; (b) a new AI-slop blocklist `scripts/launch/check_no_tutor_slop.py` covering 35 tutor-tic tokens across 4 forbidden-move categories (compliment / summary / preview / upbeat-hook), CI-gated, deep-scans every JSON string descendant so future course fixtures inherit the gate; (c) a system-instruction lock pinned by `tests/learn/test_tutor_system_instruction_lock.py`; (d) byte-equality test for the iconic 4-line opening dialog pinned by `tests/learn/test_tutor_prompts_byte_equality.py` with a dedicated U+2018/U+2019 curly-quote sentinel.

- **(P9) Course 3 citation-grounding violation.** Mitigated by (a) a new `[cue:<anchor_id>]` evidence source added via the 4-site atomic mirror pattern (mirrors v6 `[recall:]` precedent exactly across `state/evidence_registry.py` × 2 + `prompts/matrix.py` + `agent/dj_cohost.py`); (b) `tests/learn/test_no_speculative_phrase.py` AST gate landed BEFORE any Gemini wiring; (c) `bpm_confidence ≥ 0.8` AND `phrase_position_confidence ≥ 0.7` gates on count-in language; (d) past-tense pedagogy fallback when confidence below floor.

- **(P5) Pioneer/Hercules trademark copyright.** Mitigated by (a) stylized CDJ-Whisper schematic SVGs — no Pioneer logo, no Pioneer orange, no faceplate photo lift, authored from public-domain reference geometry only (CI-gated parity between SVG `data-control-id` and MIDI profile JSON); (b) disclaimer copy in app footer + repo README (`tests/learn/test_disclaimer_present.py`); (c) Mixxx-precedent nominative fair use posture — naming controllers in text ("Pioneer DDJ-FLX4") is settled-law fair use for compatibility identification.

## 4 Cardinal Invariants — pin status per phase

vibemix carries 4 cardinal invariants from v3.0 (later refined through v6/v7/v8): (#1) single-writer `MusicState`, (#2) citation-grounding for every AI claim, (#3) trust the audio (never invent events), (#4) one socket (single `127.0.0.1:8765` for `ws_bus`; `:8766` reserved for debrief). v9.0 added test-enforced pins per phase to prevent regression.

### Invariant #1 — single-writer `MusicState`

`MusicState` is write-locked to `state/refresh.py`'s state-refresh loop. Everything else is read-only. v9.0 added a private `LearnState` under `src/vibemix/learn/` with sole writer `LearnRuntime` — never touches `MusicState`.

| Phase | Pin | Test File |

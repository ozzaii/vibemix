## Are we building the right thing?

**Verdict: yes — but the project is carrying ~2-3x more surface than a coherent v1 needs, and the gap between "engine works in dev-source" and "a stranger's downloaded DMG speaks grounded words" is the entire remaining ship.** vibemix has two capability families that are deeply-built AND honest-by-construction: the grounded co-host (perception → typed event → evidence-cited prompt → MOSS reaction, gated by single-writer MusicState + EvidenceRegistry + CitationLinter + English-only guard) and the Viber/CLAP library set-prep path (Codex MCP tools + mean-centered retrieval proven on REAL vectors + cue heuristic proven on real audio). Everything else — beatmatch "Mastered", DROP-call hype line, screen vision, Mixxx OSC/db, deck-pair on Windows, mascot, demo_mode — is either WIRED_BUT_UNPROVEN, CLAIMED_BUT_ABSENT, or philosophically adverse to the anti-slop bar, and must sit OUTSIDE the v1 boundary and absent from launch copy.

**The coherent-first-product spine = (a) a co-host that SPEAKS grounded via MOSS on a stranger's machine, (b) Viber/library set-prep as the paid Pro/Studio surface, (c) ONE captured live proof of the perception loop — all behind the existing honest gates.** The engineering for this spine largely exists and is honest. What stands between source-coherent and shippable-monetized is proof/packaging gates, not new invention.

**The 3-5 things that actually block an honest ship:**
1. **MOSS reaches every machine** — not bundled in the DMG, no hosted download URL; a fresh machine boots voice-mute (`install_moss_model` errors "not hosted by default"). A mute co-host is not a product.
2. **Proxy BRAIN is live** — independent of #1: even with MOSS local, the keyless proxy brain still round-trips `api.altidus.world` and needs a working upstream Gemini key. MOSS-on-machine and proxy-brain-liveness are TWO ship gates, not one.
3. **A fresh, non-stale signed binary** — the notarized DMG is 18+ src-commits stale (`629de2e8` vs HEAD `173399ae`) and arm64-only; it predates English-only, citation-out-of-TTS, and the grounding hardening. The demoable artifact does not contain the honesty fixes.
4. **ONE captured live-rig proof of the loop** — the grounded-reaction chain, Vibe Judge, next_suggestion pill, and skill-credit are all unit/synthetic-proven only. "Real DJ friend, no AI slop" is unverified until one real event → registry-citation → grounded reaction is captured.
5. **A NOTICE/attribution file for the Mixxx clean-room ports** — Apache-2.0 binary embedding GPL-*derived* algorithms (`xfade.py`, `beatmatch_judge.py`, `transition_clock.py` carry inline derivation comments) with zero NOTICE file is an OSS-launch legal liability.

These are sequenced, not parallel: #1-in-source → fresh rebuild → live capture against the *rebuilt signed binary* (a dev-source capture proves the engine, not the artifact).

<objective>
Fix the config.json split-brain. Three Rust modules pass a RELATIVE `"config.json"` to `app.store(...)`, which tauri-plugin-store 2.4.3 resolves under the bundle-id dir (`~/Library/Application Support/world.bravoh.vibemix/config.json`), while the Python sidecar writes `~/Library/Application Support/vibemix/config.json`. The two writers touch DISJOINT files — proven on disk (Rust keys in one, Python `skill` in the other). Converge all Rust store access onto an ABSOLUTE path under the sidecar's `vibemix/` dir, reusing the helper `recordings.rs` already uses for the identical problem.

Purpose: Makes Rust + Python share ONE config file. This also makes the earlier clobber-fix (`save_state` `store.reload()`, commit f6240299) genuinely load-bearing — before this fix the two writers never collided because they wrote separate files; now they share one, so the boot-cache clobber the reload guards against can actually happen.

Output: Rust-only change (Python `config_store.py` untouched — the freshly rebuilt sidecar bundle must stay valid). One shared `config_store_path()` helper, 11 converted call sites across three modules, one promoted helper, one new unit test.
</objective>

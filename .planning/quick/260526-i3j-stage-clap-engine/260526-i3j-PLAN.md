PROVEN pipeline (from clap_mix_only.py — port EXACTLY, do not re-tune):
  CLAP_SR = 48000
  CHUNK_SAMPLES = 480000          # 10s @ 48kHz, CLAP's native clip_samples
  CHUNK_BATCH = 128               # chunks per CLAP forward pass
  - load audio (lazy torchaudio.load) → mono (mean across channels) → resample to 48kHz
  - if total <= CHUNK_SAMPLES: zero-pad to CHUNK_SAMPLES, single chunk
  - else: non-overlapping CHUNK_SAMPLES slices; a trailing remainder >= CLAP_SR*5 (5s)
    is zero-padded and kept as a final chunk
  - per chunk: clap.get_audio_embedding_from_data(batch_np, use_tensor=False)
  - L2-normalize EACH chunk emb (norm + 1e-8), mean-pool, then re-L2-normalize the mean
  - return mean_emb.astype(np.float32)  → shape (512,)

PROVEN torch loader recipe (from clap_mix_only.main() — the two monkeypatches are MANDATORY
for newer torch; restore the originals after load):
  _real_load = torch.load
  torch.load = lambda *a, **kw: _real_load(*a, **{**kw, 'weights_only': False})
  import laion_clap
  _orig_lsd = torch.nn.Module.load_state_dict
  torch.nn.Module.load_state_dict = lambda self, sd, **kw: _orig_lsd(
      self, sd, strict=False, **{k: v for k, v in kw.items() if k != 'strict'})
  clap = laion_clap.CLAP_Module(enable_fusion=True, amodel='HTSAT-tiny', device='cpu')
  clap.load_ckpt(model_id=3)      # music checkpoint
  torch.nn.Module.load_state_dict = _orig_lsd
  torch.load = _real_load

Text query path (same 512-dim space, CLAP text encoder):
  clap.get_text_embedding([text], use_tensor=False)  → (1, 512); take [0], L2-normalize.

Embedder-compatible contract (so a future ClapEmbedder wraps ClapEngine 1:1):
  embed_audio_file(path: str) -> np.ndarray   # shape (512,) float32, L2-normalized, deterministic
  embed_audio_bytes(data: bytes, mime: str) -> np.ndarray   # (512,) float32 — decode bytes → same pipeline
  embed_query(text: str) -> np.ndarray        # (512,) float32 — CLAP text encoder

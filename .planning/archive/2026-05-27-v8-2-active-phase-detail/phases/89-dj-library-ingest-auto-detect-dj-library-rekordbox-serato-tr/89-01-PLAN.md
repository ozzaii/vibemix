<objective>
The walking-skeleton ingest slice. A DJ taps once (`vibemix library ingest`,
no args): vibemix auto-detects the Rekordbox `collection.xml` at its standard
export location, parses each track via the EXISTING `RekordboxLibrary`, embeds
each on-device via the staged `clap_engine`, and stores the vectors in the
sqlite-vec library store — resumable, honest, partial-failure-tolerant. After
this slice a DJ can `library ingest` then `library search` their own crate.

Purpose: prove the full detect → parse → embed → store vertical on ONE source
(Rekordbox) end-to-end, with NO cue-anchoring yet (whole-track embed — refined
to cue-anchored in Plan 03). This is the thinnest viable slice; metadata
richness (Plan 02) and cue-anchored excerpts (Plan 03) refine it.

Output: `library/sources/` (base protocol + Rekordbox source), `library/ingest.py`
orchestrator, `vibemix library ingest` CLI, and two offline-honest-green tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| collection.xml → parser | DJ-controlled file; pyrekordbox already resilient via `_safe_get` |
| audio file → clap_engine | local file bytes; ClapEngine raises honestly on unreadable audio |
| filesystem path probe → detect() | user HOME paths; read-only stat, no execution |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-89-01 | Tampering | malformed collection.xml | mitigate | parse via existing RekordboxLibrary (pyrekordbox `_safe_get` coerces missing/odd attrs); a parse raise surfaces at the CLI, not mid-store |
| T-89-02 | Info disclosure | SQLCipher master.db | mitigate | XML-only; grep gate keeps `Rekordbox6Database`/`pyrekordbox.db6` out of new files |
| T-89-03 | Denial of service | unreadable/huge audio file | mitigate | broad-except per file → failed+continue; one bad file never aborts a 1500-file run; never stores a faked vector (Invariant #3) |
| T-89-04 | Tampering | dim mismatch (512 vs stale 1536 store) | mitigate | empty store → recreate_table; non-empty mismatch → fail-loud RuntimeError, never silently mix dims (dim flip is the CLAP-wiring session's lane) |
</threat_model>
